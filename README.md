# Talkie — じぶん英会話

対話型の英会話練習アプリ。**HTMLファイル1つだけ**で動きます。

👉 **https://shu291.github.io/eikaiwa/**

## 完全無料で動く理由

| パーツ | 使っているもの | 費用 |
|---|---|---|
| 聞き取り（音声→文字） | ブラウザ標準の Web Speech API | 0円 |
| 読み上げ（文字→音声） | ブラウザ標準の SpeechSynthesis | 0円 |
| 会話するAI | Google Gemini の無料枠 | 0円（クレカ登録なし） |
| データ保存 | ブラウザの localStorage | 0円 |

サーバーもビルドもデータベースもありません。

## 使い方

1. 上のURLを開く（マイクを使うので **Chrome 推奨**）
2. 設定タブで [Google AI Studio](https://aistudio.google.com/apikey) の APIキー（`AIza…`）を貼って「保存して確認」
3. 場面とむずかしさを選んで「会話をはじめる」

APIキーを入れなくても、**台本モード**で9つの場面を練習できます（返事はあらかじめ決まっています）。

## できること

- **11の場面** — カフェ / 入国審査 / 自己紹介 / レストラン / ホテル / 買い物 / 道を聞く / 学校の雑談 / 面接 / フリートーク / 自分で場面を書く
- **3段階のむずかしさ** — 中学英語・高校英語・ネイティブ級
- **話す** — マイクで英語を話すと文字になって送信。相手は声で返してくる
- **詰まったとき** — 「なんて言えばいい？」で言える3パターンを日本語つきで表示。日本語で話せば英語に直してくれる
- **その場で添削** — 発言ごとに「自然です」か「こう言うともっと自然」が出る
- **ふりかえりレポート** — 点数・よかった点・直す点・覚えるフレーズ・次の目標
- **フレーズ帳** — 覚えたい表現を貯めて、日本語→英語のテストで復習
- **記録** — 連続日数・週ごとのグラフ・過去の会話ログ

## プライバシー

会話の記録・フレーズ帳・APIキーは、すべて**自分の端末のブラウザの中だけ**に保存されます。作者を含む誰かのサーバーには送られません。AIモードのときだけ、会話文が Google の Gemini API に送られます。
