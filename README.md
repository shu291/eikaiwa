# Talkie — じぶん英会話

対話型の英会話練習アプリ。**HTMLファイル1つだけ**で動きます。

👉 **https://shu291.github.io/eikaiwa/**

## 完全無料で動く理由

| パーツ | 使っているもの | 費用 |
|---|---|---|
| 聞き取り（音声→文字） | ブラウザ標準の Web Speech API | 0円 |
| 読み上げ（文字→音声） | ブラウザ標準の SpeechSynthesis | 0円 |
| 会話するAI | Google Gemini の無料枠 | 0円（クレカ登録なし） |
| データ保存 | ブラウザの localStorage | 0円 |

サーバーもビルドもデータベースもありません。

## 使い方

1. 上のURLを開く（マイクを使うので **Chrome 推奨**）
2. 設定タブで [Google AI Studio](https://aistudio.google.com/apikey) の APIキー（`AIza…`）を貼って「保存して確認」
3. 場面とむずかしさを選んで「会話をはじめる」

APIキーを入れなくても、**台本モード**で9つの場面を練習できます（返事はあらかじめ決まっています）。

## できること

- **11の場面** — カフェ / 入国審査 / 自己紹介 / レストラン / ホテル / 買い物 / 道を聞く / 学校の雑談 / 面接 / フリートーク / 自分で場面を書く
- **3段階のむずかしさ** — 中学英語・高校英語・ネイティブ級
- **ハンズフリー会話** — 相手が話し終わると自動でマイクが入るので、ボタンを押さずに会話が続く
- **無音の待ち時間を調整できる** — 「何秒だまったら話し終わりとみなすか」を2〜10秒で設定（初期値4.5秒）。言葉に詰まっても勝手に送信されない
- **詰まったとき** — 「なんて言えばいい？」で言える3パターンを日本語つきで表示。日本語で話せば英語に直してくれる
- **その場で添削** — 発言ごとに「自然です」か「こう言うともっと自然」が出る
- **ふりかえりレポート** — 点数・よかった点・直す点・覚えるフレーズ・次の目標
- **フレーズ帳** — 覚えたい表現を貯めて、日本語→英語のテストで復習
- **記録** — 連続日数・週ごとのグラフ・過去の会話ログ

### 中身の量

| | 数 |
|---|---|
| 会話シーン | **23種類**（うち21はAPIキーなしの台本モードでも動く） |
| フレーズパック | 6パック **72表現** |
| 発音ドリル | 8セット・**48ペア**・24文 |
| 日替わりのお題 | **100問** |
| 会話ミッション | **38個**（レベル別） |

シーンは **定番 / 旅行 / 暮らし / 学校・仕事 / トラブル / 自由** で絞り込めます。
乗り継ぎ・タクシー・荷物紛失・診療所・美容院・ホームステイ・バイト面接・発表・グループ課題・財布の紛失・返品交換・電話 などを追加しました。

### 覚えたことを積み上げるしくみ

- **フレーズパック** — 「あいづち」「聞き返す」「気持ちを伝える」「つなぎ言葉」「意見を言う」「始め方・終わり方」。話が続かない原因はたいていここ。ワンタップでフレーズ帳に入る
- **発音ドリル** — R/L・B/V・S/TH・Z/TH・F/H・see/she・cat/cut・語末の子音。**聞き分けクイズ → 単語を言い分ける → 文で仕上げる** の3段階
- **間隔反復のフレーズ帳** — 正解するたびに次に会う日が **1 → 3 → 7 → 16 → 35 → 70日後** と伸びる。忘れた頃に出てくるので記憶に残る。間違えたものは **10分後に同じ日のうちにもう一度**
- **復習の出しかたが4種類** — 日本語→英語／🎧聞き取り（音だけ聞いて意味）／🎤発音／おまかせ（3つを混ぜる）
- **発音チェック** — お手本を聞いて自分で言うと、音声認識の結果と**単語ごとに突き合わせて一致率を表示**。言えなかった単語が赤くなる
- **弱点ノート** — 直された文が自動でたまり、**時制・冠詞・前置詞・語順・単複・単語選び…** に分類して多い順に表示。いちばん多い弱点には対処のコツが出る
- **1日の目標とリング** — 今日あと何回話せば目標かがひと目で分かる。連続日数も表示
- **レベルの自動提案** — 直近5回の平均点が高ければ「上げませんか？」、低ければ「下げませんか？」と声をかける
- **ホーム画面に追加できる（PWA）** — アプリのように起動でき、**圏外でも台本モードとフレーズ復習は動く**

### フリートークは専用のしくみ

- **相手を4人から選ぶ** — Sam（同い年の友達／米）・Emma（やさしい先生／英）・Mike（おしゃべり）・Rina（聞き上手）。性格も話し方も変わり、**声のなまりも自動で切り替わる**
- **話題を12種類から** — 今日の出来事／趣味／学校／将来の夢／食べ物／旅行／音楽・映画／スポーツ／テクノロジー／ちょっと深い話／自分で書く／おまかせ
- **今日のお題** — 30問が日替わりで出る。「このお題で話す」でそのまま会話に
- **今日のミッション** — 「I've been ~ing を使う」などをレベル別に用意。会話中に使えたら **⭐️ 達成**（AIが判定）
- **会話の長さ** — 短め5往復／ふつう10往復／じっくり20往復／**エンドレス**（自分が終えるまで続く）
- **会話中に使える助け舟** — 🐢やさしく言い直して／🔀話題を変える／🔤「これ英語でなんて言う？」（日本語で入力でも音声でもOK・例文つき）／🎚レベルをその場で切り替え
- **ふりかえりに統計** — 話した回数・使った語数・**語彙の種類**・1回あたりの平均語数・いちばん長い文
- 🎲 **全部おまかせ** ボタンで、相手も話題もミッションもランダムに

## 無料枠はどのくらい？

設定タブに **使用量カウンター**（今日つかった回数／この1分／残りの目安）が入っています。

| モデル | 1分あたりの目安 | 1日あたりの目安 |
|---|---|---|
| `gemini-2.5-flash`（初期設定） | 10回 | 250回 |
| `gemini-2.5-flash-lite` | 15回 | 1,000回 |

消費のしかたは、**自分が1回話す = 1回**／ヒント = 1回／日本語→英語 = 1回／終わりのレポート = 1回。
つまり8往復の会話まるごとで **だいたい10回**なので、1日250回なら **25会話ぶん**。ふつうに練習するぶんには足りなくなりません。

**上限を超えてもお金はかかりません。** 「今は使えません」と断られるだけで、少し待つか翌日には戻ります。
正確な枠はアカウントごとに違うので、[AI Studio の Rate limits](https://aistudio.google.com/rate-limit) で確認できます。

## ホーム画面に追加する

- **iPhone / iPad（Safari）** — 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）** — メニュー → 「アプリをインストール」
- **パソコン（Chrome）** — アドレスバー右のインストールアイコン

追加するとアドレスバーが消えて、ふつうのアプリのように起動します。

## プライバシー

会話の記録・フレーズ帳・APIキーは、すべて**自分の端末のブラウザの中だけ**に保存されます。作者を含む誰かのサーバーには送られません。AIモードのときだけ、会話文が Google の Gemini API に送られます。
